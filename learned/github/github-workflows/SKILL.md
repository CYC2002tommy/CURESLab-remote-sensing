# GitHub Workflows

Umbrella skill for managing GitHub operations via `gh` CLI or `git` + `curl`.

## Core Subsystems
See the linked reference files for detailed instructions on each subsystem:

- **Authentication:** `references/github-auth.md` - Setting up tokens, SSH, and `gh` login.
- **PR Lifecycle:** `references/github-pr-workflow.md` - Branching, committing, pushing, and merging PRs.
- **Code Review:** `references/github-code-review.md` - Reviewing PRs, inline comments, diffs.
- **Issues:** `references/github-issues.md` - Creating, triaging, labeling, and assigning issues.
- **Repo Management:** `references/github-repo-management.md` - Cloning, creating, forking, settings, releases.
